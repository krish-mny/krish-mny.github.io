Privacy Policy

Actually Free AI  ·  Last updated 7 October 2026

Summary

This site is a static page with no accounts, no logins, no analytics, no advertising and no cookies. It collects nothing about you.

A separate private tool called content-engine publishes videos to the Actually Free AI YouTube channel. It accesses exactly one YouTube account — the channel owner's own — and no one else's.

This website

These pages are served as static files by GitHub Pages. There is no database, no contact form, no tracking script and no cookie set by this site. GitHub records standard server request logs as part of hosting; see the GitHub Privacy Statement.

The content-engine tool

content-engine is a private automation tool used by the channel owner to publish their own videos. It is not a product, it has no users other than the owner, and it is not offered to anyone else.

It requests these Google OAuth scopes:

  • youtube.upload — to upload video files to the owner's own channel.
  • youtube.force-ssl — to attach captions and a thumbnail to those same uploads.

These permissions are granted once by the channel owner for their own account. The tool reads no other account, no viewer data, no comments and no analytics about individuals.

What is stored, and where

  • The OAuth refresh token is stored as an encrypted GitHub Actions secret in a private repository owned by the channel owner. It is never written to logs and never shared.
  • Generated video files, thumbnails and captions are produced during a run and uploaded to YouTube. Build artifacts are discarded afterwards.
  • A plain-text run history of topics and titles is kept in the same private repository. It contains no personal data about anyone.

No data of any kind is sold, rented, or shared with third parties.

Third-party services used

  • Google / YouTube — video hosting and the upload API.
  • Google AI Studio — generates the video scripts. Prompts contain no personal data.
  • GitHub — runs the automation and hosts this page.

Google user data and limited use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Google user data is used solely to publish the owner's own videos, is never transferred to others, is never used for advertising, and is never read by a human other than the owner.

Revoking access

The channel owner can revoke the tool's access at any time at myaccount.google.com/permissions. Doing so immediately stops all uploads.

Affiliate links

Video descriptions may contain affiliate links. If you buy through one, the channel may earn a small commission at no extra cost to you. Those links are operated by the retailer, and their own privacy policies apply once you follow them. Affiliate relationships never influence which tools are covered or what is said about them.

Children

This content is not directed at children under 13 and no information is knowingly collected from them.

Changes

If this policy changes, the date at the top of this page is updated.
